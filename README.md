# 미자모 서평 검토기

닉네임 / 카페링크 / 블로그or인스타링크 / 서점링크1 / 서점링크2 / 기타(선택) 표를 붙여넣으면
각 링크를 실제로 열어 글자수(공백 제외 500자)와 이미지 수(2장)를 확인해
OKAY(기준 충족) / CHECK(기준 미달) / 접속 불가(자동으로 못 읽음) 를 판정하는 도구입니다.

## 판정 기준

- 글자수: 공백 제외 500자 이상이면 OKAY
- 이미지: 2장 이상이면 OKAY
- URL이 아닌 일반 텍스트(예: "교보문고 my****** 2026.08.01")는 자동 OKAY
- 완전히 빈칸이면 CHECK (기준 미달)
- 기타 컬럼은 값이 있을 때만 같은 기준으로 판정에 포함되고, 없거나 빈칸이면 그냥 건너뜁니다.

## 자동으로 못 읽어서 "접속 불가"로 뜨는 경우

- 인스타그램 링크 (자동 검토 대상에서 제외)
- 네이버 카페 링크 (자동 접속이 거의 항상 차단되어 아예 시도하지 않음)
- YES24 사록(sarak.yes24.com) (자바스크립트로 본문을 불러오는 방식이라 자동 검토 불가)
- 그 외 사이트도 본문 영역을 못 찾거나, 읽은 결과가 비정상적으로 적거나(30자 미만)
  많으면(이미지 30개 초과) 잘못 읽은 것으로 보고 접속 불가로 표시합니다.

이 항목들은 CHECK(기준 미달)가 아니라 "직접 확인해주세요"라는 뜻의 접속 불가이니,
그 칸만 열어서 직접 확인해주시면 됩니다.

## Render 배포 방법 (서평러들과 공유용)

1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. https://render.com 가입 후 로그인 (GitHub 계정으로 가능)
3. 대시보드에서 "New +" -> "Web Service" 선택
4. GitHub 저장소 선택
5. Build Command: `pip install -r requirements.txt` / Start Command: `gunicorn app:app` / Instance Type: Free
6. "Create Web Service" 클릭 -> 몇 분 뒤 `https://mijamo-review-checker.onrender.com` 같은 주소 생성
7. 이 주소를 서평러들에게 공유

무료 요금제 특성상 한동안 아무도 안 쓰면 서버가 잠들어서, 오랜만에 접속하면 첫 응답이 30~60초 정도 걸릴 수 있습니다.

## 로컬에서 미리 테스트해보고 싶을 때

```
pip install -r requirements.txt
python app.py
```
브라우저에서 http://127.0.0.1:5000 접속

## 참고

이 도구는 정밀 판정이 아니라 대략적인 필터링이 목적입니다. 여전히 사이트 구조 변경이나
접근 차단으로 접속 불가가 자주 뜰 수 있으니, 그런 항목은 직접 확인해주세요.
