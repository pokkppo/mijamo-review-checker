# 미자모 서평 검토기

닉네임 / 카페링크 / 블로그or인스타링크 / 서점링크1 / 서점링크2 표를 붙여넣으면
각 링크를 실제로 열어 글자수(공백 제외 500자)와 이미지 수(2장)를 확인해 PASS / 부족 / 확인 필요를 판정하는 도구입니다.
Render에 배포해서 서평러들과 함께 링크 하나로 공유해서 쓸 수 있습니다.

## 판정 기준

- 글자수: 공백 제외 500자 이상이면 PASS
- 이미지: 2장 이상이면 PASS
- URL이 아닌 일반 텍스트(예: "교보문고 my****** 2026.08.01")는 자동 PASS
- 완전히 빈칸이면 부족
- 인스타그램 링크는 자동 검토 대상에서 제외 -> 항상 "확인 필요"
- 네이버 카페처럼 로그인이 있어야만 보이는 페이지는 자동으로 못 읽으므로 "확인 필요"로 표시

## Render 배포 방법 (서평러들과 공유용)

1. 이 폴더 전체를 GitHub 저장소에 올립니다. (Render는 GitHub 저장소를 연결하는 방식이 가장 간단합니다)
2. https://render.com 가입 후 로그인
3. 대시보드에서 "New +" -> "Web Service" 선택
4. 방금 올린 GitHub 저장소 선택
5. 아래처럼 설정 (render.yaml이 있어서 대부분 자동으로 채워집니다)
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
   - Instance Type: Free
6. "Create Web Service" 클릭 -> 몇 분 뒤 `https://mijamo-review-checker.onrender.com` 같은 주소가 생성됩니다.
7. 이 주소를 서평러들에게 공유하면 각자 접속해서 바로 쓸 수 있습니다. 비밀번호 없이 누구나 접속 가능합니다.

무료 요금제 특성상 한동안 아무도 안 쓰면 서버가 잠들어서, 오랜만에 접속하면 첫 응답이 30~60초 정도 걸릴 수 있습니다. 그 다음부터는 빠르게 동작합니다.

## 로컬에서 미리 테스트해보고 싶을 때

```
pip install -r requirements.txt
python app.py
```
브라우저에서 http://127.0.0.1:5000 접속

## 참고

이 도구는 정밀 판정이 아니라 대략적인 필터링이 목적입니다. 페이지 구조가 다르거나
이미지가 지연 로딩되는 경우 이미지 개수가 실제보다 적게 잡힐 수 있습니다.
실제로 써보시면서 특정 사이트가 계속 이상하게 나오면 알려주시면 다듬겠습니다.
